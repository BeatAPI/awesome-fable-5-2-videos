## Why 5.2, not 5.5?

Anthropic officially released **Claude Fable 5.2** on November 9, 2026. Some prelaunch collections retain creator claims labeled “Fable 5.5”. Those labels do not establish that Fable 5.2 actually ran, so we do not silently relabel or import those works.

[Official release](https://www.anthropic.com/claude-fable-and-mythos-5-2)

## Inclusion rules

- The original creator explicitly identifies Fable 5.2 and attaches the corresponding video.
- Author names link directly to the original post; publication and verification dates are retained.
- Exact prompts, source code and reference assets are recorded separately when verified. Missing fields remain unknown.
- Distinguish code-made motion, tool orchestration and assets generated by other models.
- Ambiguous model labels are excluded from the collection.
